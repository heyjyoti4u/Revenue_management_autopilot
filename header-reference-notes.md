A second horizontal content rail is visible below the header in the supplied reference, but the user explicitly wants this removed from the revised build. The requested interaction is hover-to-reveal dropdown navigation on the primary bar, not a permanently visible sub-navbar.

## Verified implementation direction
Keep one pill-shaped primary navbar with expanded left/right breathing room, active/hover underline, and dropdown menus anchored to each top-level item. Remove the always-visible secondary bar. Preserve the existing dark navy + electric violet SignalStay branding while matching the reference's spacing discipline rather than copying its identity.
